### Thread Highjacking - Local Thread(same process, same module, created by us)

- Prev knowledge: Thread context, 

| A given target thread executes our payload, not us.

- Mod the NEXT register to the payload in thread context of a suspended thread. And mod the last NEXT register in payload to address of last executed instruction within the thread to resume(happens in most payloads by default as a part of OpSec).
- Why? 
	- Relatively more stealthy than creating our own thread
	- Allows escalating privileges and exeuting payload then
	- Reduces exposure against defense solutions

❗Understanding thread and process context w.r.t. OS+arch+exn_env+etc. is imp❗

    // Set the modified thread context
    if (!SetThreadContext(hThread, &ThreadCtx)) {
        std::cerr << "[!] SetThreadContext Failed With Error : " << GetLastError() << '\n';
        return false;
